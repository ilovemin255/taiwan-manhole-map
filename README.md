## V1.25 日本マンホールカード式設計元素
GKP目前將人孔蓋圖案元素分成32類。本站加入同樣的32個分類概念：
花、木、鳥、魚、動物、昆蟲、水果、蔬菜、名物品、觀光名所、鐵道、交通工具、祭典、活動、運動、人物、文學史、傳說童話、角色、廣告宣傳、富士山、城堡、橋梁、歷史建築、幾何圖案、其他、海、山、河川、湖沼、世界遺產、下水道設施。

本站不直接複製GKP官方圖標，而使用自己的Emoji＋中文文字。
有官方名稱/說明支持的分類顯示彩色；無證據的顯示灰色。
判定採保守原則，不因為「看起來像」就自動上色。
